# hl-whale-bot

Телеграм-бот на TypeScript, отслеживающий китов биржи Hyperliquid: карточки топ-позиций, настроение «умных денег», лидерборд, слежка за кошельками с личными алертами и ежедневный PDF-отчёт в 10:00 МСК. Данные — бесплатный публичный API Hyperliquid, хостинг — GitHub Actions: проект работает без сервера и без затрат.

## Возможности

- 🐳 Топ китов — крупнейшие позиции ≥ $1M по всей бирже (плечо, вход, ликвидация, uPnL)
- 🔎 По монете — те же карточки для топ-монет + перекос лонг/шорт
- 📊 Настроение — суммарный перевес умных денег и перекос по монетам
- 🏆 Лидерборд — лучшие трейдеры по прибыли (за всё время и за сутки)
- 🐙 Слежка за китом — алерты: открыл / закрыл / перевернул / изменил позицию на 25%+
- 📄 PDF-отчёт — по кнопке и ежедневно в 10:00 МСК подписчикам

## Как запустить

### Локально

1. `npm ci`
2. Создать `.env` со строкой `BOT_TOKEN=…` (токен из @BotFather)
3. `npx tsx src/main.ts`

Смоук-тест данных без токена: `npm run smoke`.

### В GitHub Actions (без сервера)

- `bot-runner` — держит бота онлайн цепочкой ~6-часовых job-ов (каждый сам запускает следующий); старт — кнопкой «Run workflow»
- `daily-report` — ежедневный отчёт по крону `0 7 * * *` (10:00 МСК)
- Токен кладётся в секрет репозитория `BOT_TOKEN`
- Состояние (подписчики, слежка) хранится в ветке `state`

## Как устроено

1. Node 22 + TypeScript, Telegram — [grammY](https://grammy.dev) (long polling)
2. Данные — публичный `info` API Hyperliquid (`clearinghouseState`) + лидерборд `stats-data`
3. Карточки и PDF рендерит Puppeteer из HTML-шаблонов (`src/render/`)
4. Снапшот китов обновляется каждые ~4 минуты, слежка за кошельками — каждые 45 секунд
5. Тесты: `npm run typecheck`, `npx vitest run`

## Дисклеймер

Не инвестиционная рекомендация. Данные предоставляются «как есть» из публичного API Hyperliquid.
